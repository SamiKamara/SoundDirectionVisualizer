# Code of conduct

## Our standards

Contributors and users are expected to communicate respectfully, assume good faith, accept constructive technical feedback, and make the project welcoming to people with different backgrounds and accessibility needs.

Unacceptable behavior includes harassment, discrimination, threats, sexualized attention, deliberate intimidation, publishing another person's private information, or repeatedly disrupting technical discussion.

## Project scope

These standards apply in repository issues, pull requests, reviews, discussions, and other spaces where someone is representing the project. Technical disagreement is welcome when it remains focused on evidence, user impact, and the documented constraints of the audio model.

## Enforcement

The maintainer may edit or remove contributions, comments, or issues that violate these standards and may temporarily or permanently restrict participation when necessary.

Report conduct problems privately through the repository's [private advisory form](https://github.com/SamiKamara/SoundDirectionVisualizer/security/advisories/new). Do not include sensitive details in a public issue. Reports will be reviewed as privately and promptly as practical.

This code of conduct is intended to keep collaboration safe and useful; it does not replace the repository's security-reporting process in [SECURITY.md](SECURITY.md).
